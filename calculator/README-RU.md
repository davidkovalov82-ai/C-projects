# Калькулятор на C

Небольшой учебный калькулятор, написанный на C.

## Текущие возможности

- Ввод двух значений типа `double`
- Сложение, вычитание, умножение и деление
- Выбор операции с помощью `switch`
- Защита от деления на ноль
- Обработка неизвестной операции

## Пример

```text
Enter the first number: 5
Choose an operation (+, -, *, /): /
Enter the second number: 2
5.00 / 2.00 = 2.50
```

## Сборка и запуск в CLion

Открой папку проекта в CLion и запусти конфигурацию `Calculator`.

## Варианты развития

| Готово | Возможность | Ожидаемое поведение | Темы C |
|:---:|---|---|---|
| ✅ | Базовый калькулятор | Выполнять одну операцию с двумя числами | Переменные, `double`, `char`, `scanf`, `printf`, `if` или `switch` |
| ⬜ | Цепочка вычислений | Принимать любое количество чисел и операций, пока пользователь не введёт `=` | `while`, `break`, накопленный результат |
| ⬜ | Несколько вычислений | Начинать новое вычисление без перезапуска программы; выходить через `q` | `do while`, вложенные циклы |
| ⬜ | Проверка ввода | Обрабатывать текст, пустой ввод и некорректные числа | Возвращаемое значение `scanf`, очистка буфера ввода |
| ⬜ | Дополнительные операции | Добавить остаток от деления, степень и квадратный корень | `%`, `math.h`, `pow`, `sqrt` |
| ⬜ | Функции | Вынести ввод, вычисление и вывод в отдельные функции | Параметры, возвращаемые значения, прототипы функций |
| ⬜ | История | Хранить последние 10 вычислений в памяти | Массивы, структуры, строки |
| ⬜ | Меню | Добавить команды «вычислить», «показать историю», «очистить историю» и «выйти» | Циклы, `switch`, организация программы |
| ⬜ | Сохранение истории | Записывать вычисления в файл и загружать их при запуске | `FILE`, `fopen`, `fprintf`, `fgets`, `fclose` |
| ⬜ | Режим командной строки | Поддержать команды вроде `./Calculator 10 + 5` | `argc`, `argv`, `strtod` |
| ⬜ | Память калькулятора | Добавить команды `M+`, `M-`, `MR` и `MC` | Состояние программы, функции |
| ⬜ | Полные выражения | Вычислять выражения вроде `(2 + 3) * 4` с обычным приоритетом операций | Разбор выражений, приоритет операций, стек или рекурсия |

## Планируемый режим цепочки вычислений

Калькулятор должен принимать столько чисел и операций, сколько захочет пользователь:

```text
Enter the first number: 10
Choose an operation (+, -, *, /, =): +
Enter the next number: 5
Choose an operation (+, -, *, /, =): *
Enter the next number: 2
Choose an operation (+, -, *, /, =): -
Enter the next number: 3
Choose an operation (+, -, *, /, =): =
Result: 27.00
```

Первая реализация будет выполнять операции слева направо:

```text
((10 + 5) * 2) - 3 = 27
```

Обычный математический приоритет операций и скобки входят в вариант **«Полные выражения»**.
